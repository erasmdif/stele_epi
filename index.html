Marcatura tipo TEI · lingue storiche

Annota il testo, non la sua struttura.

Stele è un progetto per l'epigrafia digitale che offre due strumenti complementari: un annotatore stand-off pronto all'uso nel browser, e uno strumento desktop che gestisce interi progetti di ricerca — con vocabolari controllati, contesti archeologici, cronologie multiple e versioni testuali parallele.

𐀒𐀜𐀰  𐀀𐀂𐀒𐀨𐀩𐀁  𐀥𐀟𐀰𐀇𐀛

La marcatura è stand-off: le annotazioni fanno riferimento a porzioni di testo tramite offset, non a tag inseriti nel corpo. Puoi assegnare più note alla stessa porzione, farle sovrapporre liberamente, correggere il testo senza rompere nulla.

Prova online

Nessuna installazione. Gira nel tuo browser.

La versione web è pensata per capire cosa fa Stele in cinque minuti. Apri un testo, sottolinealo, aggiungi annotazioni, esporta in TEI-XML. I dati stanno solo nel tuo browser: nulla viene inviato a un server.

  • Annotazione stand-off con offset in code point
  • Annotazioni sovrapposte e discontinue
  • Supporto Lineare B con palette dei sillabogrammi
  • Import/export TEI-XML e JSON

Stele Desktop

DBMS completo. Gira sul tuo computer, i tuoi dati restano tuoi.

La versione desktop è il vero strumento di lavoro per un progetto epigrafico. Un database locale (GeoPackage / SQLite) tiene insieme contesti archeologici, oggetti, versioni testuali parallele, vocabolari controllati con rete semantica, cronologie multiple, luoghi geolocalizzati, bibliografia.

  • Versioni parallele allineate riga↔riga (diplomatica, traslitterazione, traduzione…)
  • Vocabolari controllati con relazioni gerarchiche ereditate
  • Cronologie visuali con datazioni multiple per metodo
  • Contesti e oggetti con campi archeologici + geolocalizzazione
  • Export TEI-XML per interoperabilità

Fondazioni tecniche

Standard aperti

Marcatura conforme alla filosofia TEI, offset in code point NFC (funziona con qualsiasi script Unicode: Lineare B, geroglifici, greco, latino, CJK). Database in formato GeoPackage OGC — apribile direttamente in QGIS.

Immutabilità e versioning

Le versioni testuali annotate sono immutabili: modificare un testo crea una nuova versione, le annotazioni vengono remappate per prefisso/suffisso comune, quelle che attraversano il punto di modifica restano sulla versione precedente e sono segnalate.

Rete semantica

I termini di dizionario (persone, luoghi, divinità, concetti) sono record condivisi: una modifica alla gerarchia di «Ares» si propaga automaticamente a tutte le annotazioni che vi puntano, senza doverle ri-esplicitare.

Local-first

Nessun account, nessun server remoto, nessuna sincronizzazione forzata. Il tuo .gpkg è il tuo progetto: lo copi, lo condividi, lo apri con altri strumenti.
