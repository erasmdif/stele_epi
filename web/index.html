Marcatura tipo TEI · lingue storiche

Annota il testo, non la sua struttura.

Stele usa una marcatura stand-off: le note fanno riferimento a porzioni di testo tramite offset, non a tag inseriti nel corpo. Così puoi assegnare più note alla stessa porzione e far sovrapporre liberamente le annotazioni — senza rompere nulla.

𐀒𐀜𐀰  𐀞𐀂𐀵  𐀀𐀖𐀛𐀰

Esempio del caso X / Z / XYZ: su 𐀒𐀜𐀰 (ko-no-so, Cnosso) puoi mettere una nota sul primo segno, una sull'ultimo e una sull'intera parola, tutte insieme e visibili come corsie parallele.

Annota un testo →

Inserisci o trascina il testo, seleziona una porzione e attribuisci una o più note. Palette Lineare B integrata e mappatura dei luoghi.

Visualizza un lavoro →

Apri un documento già prodotto (o riprendi la sessione corrente) in sola lettura, con note e mappa dei luoghi taggati.
  • Note sovrapposte e multiple sulla stessa porzione
  • Categorie con colore: lessico, persona, luogo, cronologia, nota
  • Testo a righe numerate e riferimenti r. / col. automatici
  • Scrittura Lineare B via palette o code point Unicode
  • Luoghi geocodificati (OpenStreetMap / GeoNames) su mappa Leaflet
  • Filtro note, legenda e statistiche del documento
  • Salvataggio locale + download .json e .xml (TEI-like)
  • Tutto client-side: nessun server, ok per GitHub Pages
Stele è un'app statica (v0.1.1). I documenti restano sul tuo dispositivo (salvataggio locale del browser) e sono esportabili come file scaricabili per l'archiviazione o la pubblicazione.
