TEI-inspired markup · historical languages

Annotate the text, not its structure.

Stele uses stand-off markup: notes point to spans through offsets rather than tags embedded in the text. Multiple notes can target the same span and annotations can overlap freely without breaking the document.

𐀒𐀜𐀰  𐀞𐀂𐀵  𐀀𐀖𐀛𐀰

Example of the X / Z / XYZ case: in 𐀒𐀜𐀰 (ko-no-so, Knossos), add one note to the first sign, one to the last and another to the complete word. All three remain visible as parallel lanes.
Demo disclaimer. The bundled example is a realistic-looking, fictional mock-up generated with AI to demonstrate the interface. It is not a scholarly edition and must not be treated as archaeological, epigraphic or historical evidence.

Annotate a text →

Enter or drop a text, select a span and assign one or more notes. Includes a Linear B palette and place mapping.

View a document →

Open an exported document—or resume the current session—in read-only mode, with notes and a map of tagged places.
  • Multiple overlapping notes on the same span
  • Colour-coded categories: lexical item, person, place, chronology and note
  • Numbered lines with automatic line and column references
  • Linear B input through a palette or Unicode code points
  • Geocoded places (OpenStreetMap / GeoNames) on a Leaflet map
  • Note filters, legend and document statistics
  • Local storage plus .json and TEI-like .xml downloads
  • Entirely client-side: no server and ready for GitHub Pages
Stele Web is a static application (v1.0.3). Documents remain on your device in browser storage and can be exported as downloadable files for archiving or publication.
